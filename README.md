# Enterprise Student Information & Academic Analytics System

## Project Overview
A comprehensive academic analytics and student intelligence platform developed using SQL, Power BI, and Python to analyse student engagement, classroom participation, academic performance, learning behaviour, and institutional KPIs.

---

## Tech Stack
- SQL
- MySQL
- Power BI
- DAX
- Python
- Pandas

---

## Key Features
- Student Performance Analytics
- Academic KPI Monitoring
- Engagement Analysis
- Interactive Executive Dashboards
- Advanced SQL Reporting
- Institutional Insights
- Student Behaviour Analytics
